# 📝 To-Do + Notes App

A clean and minimal **productivity web app** that lets you manage your daily tasks and take quick notes — all in one place.  
Built with a modern UI and smooth animations.

## ✨ Features

✔ Add / delete tasks  
✔ Mark tasks as completed  
✔ Create and delete notes  
✔ Smooth UI animations  
✔ Clean & minimal design  
✔ Fast & responsive  
✔ Beginner-friendly codebase
